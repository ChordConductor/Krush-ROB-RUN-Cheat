# Krush for ROB RUN (free build)

Download: soon

A free build in the spirit of Krush: role-aware ESP, aim and heist tooling for ROB RUN.

## Role-aware targeting

Krush stands out for reading player roles. Police and criminals get separate colors, so a raid reads correctly at a glance and the aim can ignore roles you do not want to shoot.

| Part | Default |
| --- | --- |
| role colors | police blue, criminal red |
| role filter | all |
| aim targets | enemy role only |
| role labels | on |

## Visuals

Player boxes with skeleton and health, cash and vehicle markers, camera ESP for security setups, loot labels with value tiers.

## Heist flow

1. Open with role colors on, mark the cash trail
2. Switch to camera ESP near vaults
3. Loot labels take over, value floor mid
4. Aim primes on the enemy role only

## Install

1. Extract, run `loader.exe` as administrator
2. Start ROB RUN
3. INSERT, load the `heist` profile
4. F6 swaps profiles

## Troubleshooting

Role colors wrong after a patch: role table is version bound, update. Aim shooting allies: role filter reset.

## Compatibility

Windows 10/11, Steam, borderless, DPI to 150%.

Free. EAC, so keep the build current.
